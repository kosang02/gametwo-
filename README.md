# 픽셀 전선 (Pixel Front 3D)

부서지는 3D 복셀 전장에서 두 군대를 배치하고 싸움을 붙이는 샌드박스 전쟁 웹게임입니다.
빌드 과정 없이 정적 파일로 동작합니다. 로컬에서는 간단한 웹 서버로 열면 됩니다.

```
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 게임 흐름
1. 왼쪽 **병기고** 서랍을 열고 팀(레드/블루)을 고른 뒤 병력을 전장에 클릭해서 배치합니다.
2. 하단 **전투 개시**를 누르면 양측 AI가 싸우기 시작합니다.
3. 전투 중에도 화력 지원(포격, 폭격기, 핵폭탄, 블랙홀 등)을 쓰거나 지형을 바꿀 수 있습니다.
4. 한쪽이 전멸하면 결과가 나오고, **같은 배치로 다시** 를 누르면 지형까지 전투 전 상태로 되돌립니다.

## 내용
- **지도 4종** (병기고의 "지도 선택"):
  - 강변 마을: 강과 다리, 벽돌 마을, 숲, 연료통 무더기
  - 사막 협곡: 절벽 고지대와 경사로, 바위 아치, 속이 연료통으로 찬 연료 저장소(연쇄 대폭발), 선인장
  - 설원 요새: 얼어붙은 호수(얼음을 깨면 물), 양쪽 성채(성벽·탑·성문·깃발), 눈 덮인 침엽수, 눈 내림
  - 폐허 도시: 도로망과 고층 빌딩(유리창), 폭발하는 자동차, 가로등, 바리케이드
- **복셀 지형**: 폭발로 파이고, 받침이 사라진 구조물은 통째로 무너져 밑의 유닛을 덮칩니다.
- **병력 14종**: 소총병, 기관총병, 돌격병(산탄), 저격병, 로켓병, 척탄병, 화염방사병, 박격포병, 폭파병, 공병, 의무병, 군견, 전차, 공격 헬기
  - 공병은 전투 시작 때 모래주머니와 지뢰를 깔고 전차를 수리합니다.
  - 폭파병은 벽이나 적에게 폭약을 붙이고 도망칩니다.
  - 헬기는 소총·기관총·저격·로켓 등 대공 가능한 병과만 맞힐 수 있습니다.
- **물리**: 폭발 넉백 래그돌, 낙하 피해, 파편 큐브, 모래 흘러내림, 불 번짐, 물 속 부력.
- **화력 지원**: 수류탄, 집속탄, 포격, 폭격기, 네이팜, 미사일, 핵폭탄, 블랙홀.
- **지형 도구**: 흙 쌓기, 파기, 콘크리트 벽, 모래주머니, TNT, 모래, 나무, 건물.
- **도구**: 시점 이동, 잡아 던지기, 유닛 관전, 유닛 제거.

## 조작
| 입력 | 동작 |
|---|---|
| 클릭 | 병력 배치, 화력 지원, 건물·나무·TNT 놓기 |
| 드래그 | 시점 이동 (잡은 땅이 커서를 따라옴). 붓·벽·잡기 도구는 그리기 |
| Shift + 드래그, 휠 클릭 드래그 | 어떤 도구든 시점 이동 |
| 우클릭 드래그, Alt + 드래그 | 회전·기울기 |
| 휠, 트랙패드 핀치 | 커서 지점을 중심으로 확대·축소 |
| W A S D · Q E · Z X · PageUp/Down | 이동 · 회전 · 확대 · 기울기 (Shift로 빠르게) |
| R | 전장 전체 보기 |
| 한 손가락 (모바일) | 탭 배치, 끌어서 이동 |
| 두 손가락 (모바일) | 벌려서 확대, 비틀어 회전, 함께 위아래로 기울기 |
| 오른쪽 아래 버튼 | 회전 · 기울기 · 확대 · 전체 보기 |
| B / Tab | 병기고 열기·닫기 |
| T | 배치 팀 바꾸기 |
| Enter · Space | 전투 개시 · 일시정지 |
| F | 전체 화면 |
| H | 조작법 |
| Esc | 관전 끝내기 / 창 닫기 |

## 파일 구성
- `index.html`, `style.css`: 화면 구성과 스타일
- `js/world.js`: 복셀 데이터, 지형 생성, 청크 메싱(AO), 레이캐스트, 구조 붕괴
- `js/fx.js`: 파편 물리, 파티클, 예광탄, 조명, 사운드(WebAudio 합성)
- `js/units.js`: 유닛 종류, 이동 물리, AI, 길찾기, 렌더링
- `js/combat.js`: 투사체, 폭발, 화재, 지원 화력
- `js/ui.js`: 도구 동작, 병기고, HUD
- `js/camera.js`: 카메라(땅 잡고 끌기, 커서 기준 확대, 관전), 마우스·터치·키보드 입력
- `js/main.js`: 렌더러 설정, 게임 흐름, 메인 루프
- `vendor/three.min.js`: three.js r149
