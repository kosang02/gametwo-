# 픽셀 전선 (Pixel Front 3D)

부서지는 3D 복셀 전장에서 두 군대를 배치하고 싸움을 붙이는 샌드박스 전쟁 웹게임입니다.
빌드 과정 없이 정적 파일로 동작합니다. 로컬에서는 간단한 웹 서버로 열면 됩니다.

```
python3 -m http.server 8000
# http://localhost:8000 접속
```

## 게임 흐름
1. 왼쪽 **병기고** 서랍을 열고 팀(레드/블루)을 고른 뒤 병력을 전장에 클릭해서 배치합니다.
2. 하단 **전투 개시**를 누르면 양측 AI가 싸우기 시작합니다.
3. 전투 중에도 화력 지원(포격, 폭격기, 핵폭탄, 블랙홀 등)을 쓰거나 지형을 바꿀 수 있습니다.
4. 한쪽이 전멸하면 결과가 나오고, **같은 배치로 다시** 를 누르면 지형까지 전투 전 상태로 되돌립니다.

## 내용
- **복셀 지형**: 강, 다리, 벽돌·콘크리트 건물, 감시탑, 숲. 폭발로 파이고, 받침이 사라진 구조물은 통째로 무너져 떨어지며 밑에 깔린 유닛에 피해를 줍니다.
- **병력**: 소총병, 기관총병, 저격병, 로켓병, 척탄병, 의무병, 전차. 흐름장 길찾기로 강과 건물을 돌아가고, 막히면 벽을 폭파하거나 점프합니다.
- **물리**: 폭발 넉백 래그돌, 낙하 피해, 파편 큐브 물리, 모래 흘러내림, 불 번짐(나무·잎·판자), 물 속 부력.
- **화력 지원**: 수류탄, 집속탄, 포격, 폭격기, 네이팜, 미사일, 핵폭탄, 블랙홀.
- **지형 도구**: 흙 쌓기, 파기, 콘크리트 벽, 모래주머니, TNT, 모래, 나무, 건물.
- **도구**: 시점 이동, 잡아 던지기, 유닛 관전(3인칭 추적), 유닛 제거.

## 조작
| 입력 | 동작 |
|---|---|
| 좌클릭 / 드래그 | 선택한 도구 사용 |
| 우클릭 드래그 | 시점 회전 |
| Shift + 드래그, 휠 클릭 드래그 | 시점 이동 |
| 휠 | 확대·축소 |
| W A S D · Q E · Z X | 이동 · 회전 · 확대 |
| 두 손가락 (모바일) | 이동·회전·확대 |
| B / Tab | 병기고 열기·닫기 |
| T | 배치 팀 바꾸기 |
| Enter | 전투 개시 |
| Space | 일시정지 |
| F | 전체 화면 |
| H | 조작법 |
| Esc | 관전 종료 / 창 닫기 |

## 파일 구성
- `index.html`, `style.css`: 화면 구성과 스타일
- `js/world.js`: 복셀 데이터, 지형 생성, 청크 메싱(AO), 레이캐스트, 구조 붕괴
- `js/fx.js`: 파편 물리, 파티클, 예광탄, 조명, 사운드(WebAudio 합성)
- `js/units.js`: 유닛 종류, 이동 물리, AI, 길찾기, 렌더링
- `js/combat.js`: 투사체, 폭발, 화재, 지원 화력
- `js/ui.js`: 카메라, 입력, 병기고, HUD
- `js/main.js`: 렌더러 설정, 게임 흐름, 메인 루프
- `vendor/three.min.js`: three.js r149
