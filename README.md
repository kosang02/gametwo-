# 픽셀 전선 (Pixel Front)

도트 샌드박스 전쟁 웹게임입니다. 빌드나 서버 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 특징
- **샌드박스 물리**: 모래, 흙, 돌, 강철, 나무, 물, 기름, 용암, 산성액, 화약, TNT, 불이 서로 반응합니다.
  예: 용암과 물이 만나면 돌과 수증기가 되고, 불은 나무·기름·풀로 번지며, 화약과 TNT는 연쇄 폭발합니다.
- **파괴 가능한 지형**: 폭발하면 지형이 파편으로 날아가 흩어지고, 떨어진 곳에 다시 쌓입니다.
- **AI 군대**: 레드/블루 두 팀의 소총병, 저격병, 바주카병, 척탄병, 전차가 서로 싸웁니다.
  넉백, 낙하 피해, 화상, 익사, 산성 피해가 적용됩니다.
- **지원 화력**: 수류탄, 집속탄, 네이팜(새총 방식으로 드래그해서 투척), 미사일, 공습, 핵폭탄, 블랙홀.
- **잡아 던지기**: 병사나 전차를 잡아서 던질 수 있습니다.

## 조작
| 입력 | 동작 |
|---|---|
| 좌클릭 드래그 | 선택한 재료 칠하기, 유닛 배치, 무기 사용 |
| 우클릭 | 재료 지우기 / 반대 팀 유닛 배치 |
| Space | 일시정지 |
| S | 슬로모션 |
| A | 자동 증원 켜기/끄기 |
| R | 새 전장 |
| `[` `]` | 붓 크기 |

## 파일
- `index.html`: 페이지 구조
- `style.css`: UI 스타일
- `game.js`: 시뮬레이션, AI, 렌더링, 사운드(WebAudio 합성)
